# Қызметкерлердің кестесін ескере отырып, университеттің тұрақ орындарын жоспарлаудың интеллектуалды жүйесі

Автор: Ермекұлы Қуаныш, ВтиПО ук 25-5

## Мәселе

Университет аумағындағы тұрақ орындары шектеулі, ал қызметкерлердің жұмыс кестесі әртүрлі болғандықтан, орындар біркелкі пайдаланылмайды: бір уақытта тығыздық пайда болады, басқа уақытта орындар бос тұрады. Жүйе қызметкердің кестесін ескеріп, тұрақ орнын алдын ала жоспарлайды және брондайды. Ол университет қызметкерлеріне және тұрақты басқаратын әкімшілікке керек.

## Акторлар

* Қызметкер
* Әкімші (тұрақ орындарын және брондауларды басқарады)

## Талаптар

### Функционалдық

1. Жүйе қызметкердің жұмыс кестесін ескеріп, келу уақытын анықтауы керек
2. Жүйе таңдалған күні бос тұрақ орындарын көрсетуі керек
3. Жүйе қызметкерге оңтайлы орынды ұсынып, брондауды сақтауы керек
4. Орын жоқ болса, жүйе қызметкерді күту тізіміне қосуы керек
